Hi, I’m **Mathew Robertson**, an astrophysics PhD graduate transitioning into **data science and analytics**.

During my PhD I worked on large, noisy datasets from cosmology, building end-to-end pipelines in **Python** and running them on **high-performance computing clusters**. That meant a lot of data cleaning, modelling, statistical inference, and optimisation to make code run efficiently at scale.

I’m now focusing these skills on real-world problems in industry, particularly roles that involve:

- Analysing complex datasets to generate clear, actionable insights  
- Building reproducible data pipelines in **Python** and **SQL**  
- Applying statistics and machine learning in a practical way  
- Communicating results to non-technical stakeholders

A few things I’m comfortable with:

- **Python:** pandas, numpy, matplotlib, Jupyter, basic scikit-learn  
- **Data:** cleaning, feature engineering, exploratory analysis, visualisation  
- **Stats:** regression, uncertainty quantification, experiment / A/B-style thinking  
- **Tools:** Git/GitHub, Linux, working on remote compute environments
